# 玩家武功成长修复实施说明

本任务仅适用于新剑侠情缘(sword1)与月影传说(demo)中API userType=player的记录，并且仅在玩家本人背包选择启用。剑侠2、NPC和伙伴背包不启用。原始缓存、API、数据库不变。

## 已核实来源与处理决定

2026-09-09从Upwinded/JXQY-all-in-one resources发布包按ZIP Range读取配置，逐项验证CRC32及大小；来源URL、文件名、SHA256见sources.json。发布者标注原版；它是公开移植资源，不将其声称为已认证零售光盘原文件。

- 掌上生雷、天外飞仙、天魔解体大法、梅花镖、袖箭：发布包1—10级的Effect/ManaCost/LevelupExp均为空，与当前API零值对应，不能称为导入丢失。
- 天魔解体大法：script/map/map084_金兵主帅营/天魔解体死亡.txt通过剧情、动画和地图切换表现代价，不新增伤害/自残玩法。
- 梅花镖：原INI GoodsName=goods062_梅花镖.ini；相关goods062/goods075/goods076的Init均标注“当作物品”。两类暗器本次保持配置，不误改成修炼技能。
- player-levelup-1/2：仅角色升级特效，无等级表，保持原状。
- 经验倒退或重复在来源中也存在：碧海潮生、潮生碧海、幻影飞狐、满江红及云生结海。本次纠正累计阈值顺序，效果值（包括负值）、耗蓝、速度、形态均保留。

## 经验阈值修正

只匹配完整已核实旧1—9级经验序列，后续人为调整的新曲线优先，不执行普遍或动态归一化。

- sword1 碧海潮生：2级300→900（邻近400/1400中点），其余不变。
- sword1 潮生碧海：2级800→1150（邻近800/1500中点），其余不变。
- sword1 幻影飞狐：7/8/9级15000/24000/32000→60000/71000/82000，延续此前38000→49000的11000步长。修炼至10级的总经验上升；已有等级不降低、已有经验不清空。
- sword1 满江红：5—9级重复50000→60000/70000/80000/90000/100000，延续原先每级10000步长。保留效果和满级高耗蓝，后者不是本次成长异常修复对象。
- sword1/demo 云生结海：8级40000→52000（邻近40000/64000中点），9级仍64000。10级原100000由现有getMagicAtLevel封顶为0，不增加11级。

## 调用和兼容约束

PlayerBase → new PlayerMagicInventory(true) → getConfiguredMagic → repairPlayerMagicProgression。从当前API玩家桶验证userType，只有玩家背包启用。默认new PlayerMagicInventory()保持NPC/伙伴和旧调用行为。

面板学习、批量/隐藏/修炼/快捷栏存档加载、替换列表和资源重载采用同一配置入口；普通NPC武功cache与getMagic保持原数据。修复克隆Map和被改变的等级对象，不污染共享缓存。存档等级、累计经验、冷却等条目状态保留，不自动清理已持有的禁用技能。

仅改玩家运行时配置，后台仍显示存储的原始数值。没有写数据库、发布或手动控制CI；用户已授权正常push main，完成审查修复与构建后执行。

## 验证

见state.json：定向测试包括累计经验1→10封顶，50/500/2000攻击基线下效果单调，所有玩家存档位置、替换列表、缓存不变、其他游戏及非玩家排除、作者后改配置优先。新数值的长期战斗平衡仍需后续实战反馈，不宣称完成全剧情通关验证。

Bugbot审查发现资源重载遗漏变身列表缓存，已在MagicListReplace.reloadAllMagics刷新活动、非活动及隐藏列表，并由PlayerMagicInventory.reloadAllMagics调用；保留条目身份、等级、经验及冷却。35项测试通过，TypeScript及Vite/PWA生产构建通过。构建仍有既有资源域名占位、WASM外部模块、bundle大小及Browserslist提示；不等同于线上部署验证。
